# Foliolum

Foliolum is a page layout tool that runs in the browser, for parishes, schools, nonprofits and small
groups. If you have made a bulletin, a newsletter or a flyer in Microsoft Publisher, it should feel
familiar. It is early: there is nothing to install or use yet. It will build on the open-source
DesignCraft engine.

Site: https://foliolum.app (coming soon). Guides: https://docs.foliolum.app.
